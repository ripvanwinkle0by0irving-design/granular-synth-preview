粒音 DRONE ENGINE / 0.6a

GRAINとSPECTRAL。音の粒と周波数を彫刻する。

01 / CAPTURE — 音を採集

録音開始を押すとマイクの許可を求めます。

サンプル未読み込み

02 / WAVE EDIT — 波形を編集

波形の上を指でなぞって範囲を選択します。両端の丸いハンドルをドラッグすると微調整できます。

範囲を選んでください—

録音または音声ファイルの読み込み後に編集できます。編集結果は再生・WAV書き出しにも反映されます。

03 / PLAY — 粒子を漂わせる

録音またはファイルを読み込んでください。

04 / DUAL ENGINE — 音の加工方式

GRAIN：粒の長さ・密度・揺らぎを再生中に変更できます。
50%

Freezeは選んだ瞬間の周波数を持続音にします。Drone LoopはFreeze時のみ有効です。設定変更時は停止・再解析します。通常SPECTRALは最大60秒、内部解析は32MBまで。処理中は停止ボタンで中止できます。

05 / SCULPT — 音を彫刻する

FREEZEは波形を進む動きを止めます。REVERSEは粒を逆向きに再生します。

波形を進む速さを調整します。音程は変わりません。

06 / EXPORT — 音を残す

選択中のGRAIN/SPECTRALエンジンで指定秒数のWAVを生成します。SPECTRALは先に解析します。録音した元の音は送信されません。

音声を読み込むと書き出せます。

Version 0.6a 試験版：GRAIN＝グラニュラー方式、SPECTRAL＝周波数分析による位相ボコーダー方式（試験実装）。SPECTRALの設定変更後は再生時に再解析します。高倍率では音質が変化します。音声を何倍にも引き伸ばしてファイルとして出す場合は、WAV書き出し時間も適切に選んでください。
iPhone Chrome / Safari対応。マイク利用にはHTTPSと使用許可が必要です。録音音声は端末内で処理し、ネットへ送信しません。ヘッドフォンを推奨します。画面ロック中の再生は保証されません。
